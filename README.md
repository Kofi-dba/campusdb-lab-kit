# CampusDB Labs — Database Administration & Security

Your own MySQL 8.0 server in the browser. No installs.

**Students:** start with [`labs/00-getting-started.md`](labs/00-getting-started.md).
Every lab: `labctl hello N` → `labctl start-lab N` → do the lab → `labctl submit N`.
