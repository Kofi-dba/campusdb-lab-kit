# CampusDB Labs — Database Administration & Security (Weeks 1–4)

Your own MySQL 8.0 server in the browser. No installs.

**Students:** click **Code ▸ Codespaces ▸ Create codespace on main**, then follow
[`labs/00-getting-started.md`](labs/00-getting-started.md).

| Week | Lab | You will… |
|---|---|---|
| 1 | [Meet the database](labs/lab1-meet-the-database.md) | Log in, explore the server, see why the DBMS is the only gate |
| 2 | [Build CampusDB](labs/lab2-build-campusdb.md) | Build tables with keys and constraints, break the rules on purpose, back up and restore |
| 3 | [Lock it down](labs/lab3-lock-down.md) | Users, roles, views and least privilege |
| 4 | [Defend it](labs/lab4-defend.md) | SQL injection, TLS, audit trails, encrypted backups, hardening |

Stuck or missed a week? `labctl help` · `labctl start-week N`

**Lecturers:** see [`instructor/INSTRUCTOR-GUIDE.md`](instructor/INSTRUCTOR-GUIDE.md).

All data in CampusDB is fictional. Never load real personal data into a lab server.
